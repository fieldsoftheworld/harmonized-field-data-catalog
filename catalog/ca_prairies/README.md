# Field boundaries for the Canadian Prairies, derived from Sentinel-2

Field boundaries for Alberta, Saskatchewan and Manitoba, segmented from Sentinel-2 imagery of
2021-2024 with the Segment Anything Model by the University of Saskatchewan. The boundaries are
derived, not declared: no farmer or authority drew them. Seasonal RGB composites were segmented
without training data, the polygons cleaned and smoothed, and only those of at least 2 ha that
mostly lie on cropland (AAFC Annual Crop Inventory and ESA WorldCover) were kept. One file per
rural municipality (RM).

- **Source data provider:** [University of Saskatchewan](https://doi.org/10.17632/2y568rt76w.2)
- **License:** CC-BY-4.0
- **Editions:** 2024 (one GeoParquet per year)
- **Fields in the latest edition (2024):** 656,082
- **Coordinate reference system:** EPSG:4326 (as published by the source; not reprojected)
- **Converted with:** fiboa-cli 0.21.0, vecorel-cli 0.4.1 ([converter](https://github.com/fiboa/cli/blob/main/fiboa_cli/datasets/ca_prairies.py))

Browse this collection in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/harmonized-field-data/ca_prairies/collection.json), or start from the [AGENTS.md](https://source.coop/ftw/harmonized-field-data/ca_prairies/AGENTS.md) for tested queries.

## Columns

| Column | Type | Description |
|---|---|---|
| `metrics:perimeter` | float | Perimeter of the field, in meters (m). Must be > 0 and <= 125,000. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `admin:subdivision_code` | string | ISO 3166-2 code for the principal subdivision (e.g., province or state, aka admin1) of a country that contains the field. | `admin_local_code` | string | Carried over from the source column `RM_number`; the publisher documents no meaning for it. |

| `geometry` | binary | A geometry that reflects the footprint of the field, usually a Polygon. Stored in the source CRS (see `proj:code`), not reprojected. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `id` | string | An identifier for the field. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `admin_local_name` | string | Carried over from the source column `RM_name`; the publisher documents no meaning for it. |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> | The bounding box of the field. Per-feature covering column (GeoParquet 1.1), in the source CRS. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |

- `admin:country_code`: `CA`

## Access

Query the published files in place with DuckDB; nothing needs downloading first.

```sql
INSTALL spatial; LOAD spatial; INSTALL httpfs; LOAD httpfs;
SELECT count(*) AS fields, round(sum("metrics:area") / 1e4) AS hectares
FROM read_parquet('https://data.source.coop/ftw/harmonized-field-data/ca_prairies/latest/ca_prairies.parquet');
-- fields | hectares
-- 656082 | 28475726.0
```
