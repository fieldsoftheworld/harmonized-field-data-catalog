# Trazo field boundary annotations for South America with splits

Agricultural field boundaries drawn by hand by World Resources Institute (WRI) and Arizona State
University annotators (in Paraguay with Mundo Agropecuario) in 25 sampling regions across South
America, 2020-2024, to adapt the
Fields of The World (FTW) field boundary models to South American agriculture. The regions are
ecoregions (Chaco, Chiquitania, Araucaria, Amazon, Cerrado, Caatinga, Pampas and others) where the
baseline model performed poorly, about 500 samples in Paraguay from Mundo Agropecuario's data,
Mato Grosso samples chosen by active learning, and three randomly sampled test regions.

Each region was annotated for one year, which is each field's determination date (1 January of
that year). The three test regions (`testchiquitania`, `testmatogrosso`, `testsoy`) were sampled
randomly, the statistically rigorous choice for evaluation; the others were chosen for poor model
performance, a query strategy or partner data (WRI's own chip files split those about 90/10 into
train and val). `wri_trazo_ml` adds a `split`: `test` for the three test regions, `train` for the
others. Some Mato Grosso regions
overlap: a few `testmatogrosso` fields are also labelled in train regions, and many
`matogrosso_brazil_lowconfidences` fields are also in `matogrosso_brazil_confidences`.
`basemap` is the imagery the annotators drew on: monthly Planet basemaps or, in three regions,
Sentinel-2 alone. Polygons that a source file holds twice are kept once.

Every field inside the 256x256 Sentinel-2 chips of WRI's training data is annotated; annotations
that reach beyond a chip are kept, but land outside the chips is not completely labelled.

Grupp et al. (2026): Field Boundaries of South America. World Resources Institute & Arizona State
University, https://www.wri.org/research/field-boundaries-south-america

- **Source data provider:** [World Resources Institute and Arizona State University](https://source.coop/wri-data-lab/trazoannotations)
- **License:** CC-BY-4.0
- **Editions:** 2020, 2021, 2022, 2023, 2024 (one GeoParquet per year)
- **Fields in the latest edition (2024):** 6,092
- **Coordinate reference system:** EPSG:4326 (as published by the source; not reprojected)
- **Converted with:** fiboa-cli 0.30.0, vecorel-cli 0.4.4 ([converter](https://github.com/fiboa/cli/blob/main/fiboa_cli/datasets/wri_trazo_ml.py))

Browse this collection in the [data browser](https://browser.portolan-sdi.org/#/external/data.source.coop/ftw/harmonized-field-data/wri_trazo_ml/collection.json), or start from the [AGENTS.md](https://source.coop/ftw/harmonized-field-data/wri_trazo_ml/AGENTS.md) for tested queries.

## Columns

| Column | Type | Description |
|---|---|---|
| `id` | string | An identifier for the field. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `geometry` | binary | A geometry that reflects the footprint of the field, usually a Polygon. Stored in the source CRS (see `proj:code`), not reprojected. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `determination:datetime` | timestamp[ms, tz=UTC] | The last timestamp at which the field did exist and was observed. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `region` | string | Source-specific column; the publisher documents no meaning for it. |
| `basemap` | string | Source-specific column; the publisher documents no meaning for it. |
| `split` | string | Source-specific column; the publisher documents no meaning for it. |
| `metrics:area` | float | Area of the field, in square meters (m²). Must be > 0 and <= 1,000,000,000. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |
| `bbox` | struct<xmin: double, ymin: double, xmax: double, ymax: double> | The bounding box of the field. Per-feature covering column (GeoParquet 1.1), in the source CRS. ([spec](https://github.com/fiboa/specification/blob/main/core/README.md)) |

Properties that are the same for every field are stored once, in the GeoParquet file's `collection` metadata rather than as columns (latest edition shown; a client reading only the table will not see them):

- `determination:method`: `manual`

## Access

Query the published files in place with DuckDB; nothing needs downloading first.

```sql
INSTALL spatial; LOAD spatial; INSTALL httpfs; LOAD httpfs;
SELECT count(*) AS fields, round(sum("metrics:area") / 1e4) AS hectares
FROM read_parquet('https://data.source.coop/ftw/harmonized-field-data/wri_trazo_ml/latest/wri_trazo_ml.parquet');
-- fields | hectares
-- 6092 | 267027.0
```
